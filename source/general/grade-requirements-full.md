## Основы JavaScript — УМЕЕТ

### Junior

- Применять унарные и бинарные операторы, включая префиксную/постфиксную форму и сокращённые записи (+=, ++ и др.)
- Предсказывать результат операций с неявным приведением типов (например, '5' + 3, [] + {})
- Использовать == и === корректно, объяснять разницу на практике
- Строить условия с if, else, ? :, в том числе вложенные
- Применять ||, &&, !, ?? в выражениях, использовать короткое замыкание для присваивания
- Объявлять функции через function declaration, function expression, использовать стрелочные функции с учётом их особенностей
- Применять циклы для обработки массивов, объектов и других структур данных
- Преобразовывать типы явно и неявно: String(), Number(), Boolean(), +, !!
- Проверять типы данных с пониманием особенностей оператора typeof
- Определять значение this в глобальном контексте (window / global)
- Создавать простые замыкания (например, функцию, возвращающую счётчик)
- Строить цепочки промисов с .then(), обрабатывать ошибки через .catch(), использовать .finally()

### Middle

- Создавать объекты с нужным прототипом (Object.create, ручное присвоение prototype)
- Применять деструктуризацию объектов и массивов, включая вложенные структуры и значения по умолчанию
- Корректно использовать ?? вместо || при работе с 0, '', false
- Объяснять и предсказывать результат приведения типов с помощью ToPrimitive, valueOf, toString
- Преобразовывать данные с помощью JSON.stringify (с replacer, space) и JSON.parse (с reviver)
- Применять map, filter, reduce для трансформации массивов, избегать мутаций при необходимости
- Реализовывать стек и очередь на основе массивов (push/pop, unshift/shift)
- Управлять значением this с помощью call, apply, bind (например, передача контекста в колбэки)
- Писать асинхронный код с async/await
- Обрабатывать ошибки через try...catch
- Использовать Promise.all, Promise.allSettled для параллельного выполнения, выбирать подходящий метод в зависимости от требования
- Реализовывать наследование через функции-конструкторы и prototype
- Писать классы с использованием class, extends, super, геттеров/сеттеров, статических методов
- Создавать class и функции-конструкторы

### Senior

- Применять ...rest и ...spread корректно для объектов и массивов, избегая неглубоких копий при вложенных структурах
- Преобразовывать объекты и коллекции с помощью Object.fromEntries, Array.from, Object.entries — например, фильтрацию ключей объекта через массив
- Создавать объекты с контролируемыми свойствами: неизменяемые (freeze), скрытые (enumerable: false), с геттерами/сеттерами через defineProperty
- Использовать Map и Set вместо объектов и массивов при работе с динамическими ключами, частыми вставками/удалениями
- Применять WeakMap и WeakSet для хранения метаданных, подписок или кэшей без утечек памяти (например, привязка данных к DOM-узлам)
- Сохранять контекст в колбэках с помощью bind, стрелочных функций или проксирования, предотвращая потерю this
- Проектировать чистые функции и иммутабельные преобразования данных, минимизируя побочные эффекты
- Писать и использовать каррированные и частично применённые функции с bind
- Применять рекурсивные функции с учетом производительности браузера
- Обрабатывать асинхронные потоки данных с помощью for await...of
- Реализовывать инкапсуляцию с помощью #private полей и методов, избегая утечки внутренней логики классов
- Создавать иерархии классов с extends и super, корректно вызывая super() и используя super.method() с учётом контекста
- Использовать статические методы и свойства в классах, применяя их для создания утилитарных функций или управления состоянием класса

### Staff

- Писать высокопроизводительный код, минимизируя аллокации, избегая деоптимизаций (например, мегаморфизмы) и работая с памятью эффективно
- Разрабатывать архитектуру приложений, с учетом поддержания производительности и читаемости кода
- Проектировать и разрабатывать библиотеки и фреймворки с учетом современных стандартов
- Создавать новые паттерны, инструменты или библиотеки
- Анализировать текущие тенденции в развитии JavaScript и предлагать стратегические решения для внедрения новых технологий и подходов

### Junior

- CustomEvent и dispatchEvent для создания собственных событий
- Touch events и pointer events для мобильных устройств
- IndexedDB для хранения структурированных данных
- Cache API и стратегии кэширования с версионированием
- Как синхронизировать данные и состояния между вкладками (BroadcastChannel, SharedWorkers, события storage)
- Особенности работы в private mode (инкогнито)
- Web Workers для фоновых вычислений
- Service Workers: push-уведомления, offline режим, фоновая синхронизация
- Observer APIs
- AbortController для отмены запросов по таймауту
- WebSockets и Server-Sent Events для real-time коммуникации

### Staff

- Внутренние механизмы браузера: Layout, Paint, Composite pipeline
- Механизмы регидрации и гидрации в DOM
- Event-driven архитектуру и её паттерны
- Passive listeners и их влияние на производительность при скроллинге
- Архитектурные паттерны offline-first решений
- Подходы к миграции данных и обеспечению backward compatibility
- Полифиллы и fallback-стратегии для поддержки старых браузеров
- Ограничения и особенности различных браузерных API
- Intersection Observer API для реализации lazy loading
- File API для работы с файловой системой
- Современные Web API и их интеграцию в сложные системы
