## Для перехода Middle → Senior (целевые уровни)

- **Жизненный цикл разработки ПО** — уровень **3**/4
  - Методологии разработки
  - Оценка трудоемкости разработки
  - Releases
  - Система контроля версий

- **Обеспечение качества** — уровень **3**/4
  - Основы авто-тестирования
  - Unit tests
  - Анализаторы кода
  - Технический долг и рефакторинг
  - CI/CD
  - Quality Gates
  - Практики Code Review
  - Best Practices

- **Работа с инструментами ИИ** — уровень **3**/4
  - Модели ИИ и технические аспекты
  - Работа с копайлотами и агентами
  - Промпт-инженеринг
  - Интеграция в продукты

- **Структуры данных и алгоритмы** — уровень **2**/4
  - Cтруктуры данных, виды и принципы работы
  - Алгоритмы сортировки и поиска
  - Алгоритмы для ограничения скорости передачи данных и частоты операций
  - Алгоритмическая сложность и производительность

- **Паттерны разработки** — уровень **3**/4
  - ООП и Функциональное программирование
  - Принципы проектирования
  - Подходы проектирования
  - Шаблоны проектирования

- **Архитектура** — уровень **2**/4
  - Архитектурные стили
  - Архитектурные паттерны
  - Системный дизайн
  - Высоконагруженные системы
  - Observability

- **Инфраструктура и Cloud** — уровень **1**/4
  - Облачные технологии
  - Балансировщики нагрузки
  - Proxy
  - Сеть доставки контента (CDN)
  - Контейнеры и оркестраторы
  - Брокеры сообщений
  - Кеширование

- **Протоколы, API** — уровень **3**/4
  - Структуры передачи данных
  - Сетевая модель OSI и протоколы
  - Протоколы реализации API
  - Идемпотентность
  - Подходы к коммуникации с сервисами

- **Безопасность** — уровень **3**/4
  - Аутентификация и авторизация
  - Системы контроля безопасности
  - Риски безопасности OWASP
  - Безопасность данных при хранении и передаче
  - Безопасность на стороне сервера
  - CORS
  - Certs

- **Базы данных** — уровень **1**/4
  - Реляционные БД
  - NoSQL/Нереляционные БД
  - Основы SQL
  - Масштабирование БД
  - Оптимизация БД
